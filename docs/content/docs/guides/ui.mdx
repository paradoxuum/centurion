The `centurion-ui` package provides a terminal UI that has command history, suggestions, and tab completion.

## Mounting

`mount` is used to create the UI. By default, the terminal is opened and closed with `F2`. To use different keys, pass a list of `KeyCode` values.
`mount` only takes effect the first time it's called; use `configure` to change the keys afterwards.

## Configuration

Call `configure` with a partial options table. All fields are optional, omitted fields keep their current values.

```lua
centurion_ui.configure({
    hide_on_lost_focus = true,

})
```
  </CodeBlockTab>

### Options Reference

| Option | Type | Description |
| --- | --- | --- |
| `hide_on_lost_focus` | `boolean` | Close the terminal when clicking outside of it |
| `activation_keys` | `KeyCode[]` | Keys used to open or close the terminal |
| `theme` | `Theme` | The terminal's color theme |
| `font` | `Font` | Font used for all terminal text |
| `icon` | `string` | Asset ID of the icon shown in the terminal |
| `transparency` | `number` | Background transparency of the terminal (default: 0.2) |
| `text_size` | `number` | Primary text size |
| `subtext_size` | `number` | Secondary text size (command/argument descriptions) |
| `max_suggestions` | `number` | Maximum number of autocomplete entries shown (default: 5) |
| `clear_button` | `boolean` | Show a button in the header that clears the command log (default: false) |
| `anchor` | `Vector2` | Anchor point of the terminal window |
| `position` | `UDim2` | Position of the terminal window |
| `width` | `UDim` | Width of the terminal window |
| `format_date` | `(log) -> string` | Custom timestamp formatter for log entries |

## Built-in Commands

Call `register_commands()` to add the built-in terminal commands to the registry.

<CodeBlockTabs groupId="lang" defaultValue="luau" persist>
  <CodeBlockTabsList>
    <CodeBlockTabsTrigger value="luau">Luau</CodeBlockTabsTrigger>
    <CodeBlockTabsTrigger value="ts">TypeScript</CodeBlockTabsTrigger>
  </CodeBlockTabsList>
  <CodeBlockTab value="luau">
```lua
centurion_ui.register_commands()
```
  </CodeBlockTab>
  <CodeBlockTab value="ts">
```ts
CenturionUI.register_commands();
```
  </CodeBlockTab>
</CodeBlockTabs>

This registers:

| Command | Description |
| --- | --- |
| `clear` | Clears the command log history |
| `theme <name>` | Switches to a built-in theme |

Pass `exclude` to skip some of them, or `prefix` to group them under a name so they don't collide with your own commands:

```lua
centurion_ui.register_commands({
    prefix = "centurion", -- registers "centurion clear"
    exclude = { "theme" }, -- skips "theme"
})
```

## Themes

Five built-in themes are available, all based on the [Catppuccin](https://catppuccin.com) palette plus a Roblox default.

| Name | Description |
| --- | --- |
| `mocha` | Dark, warm background (default) |
| `macchiato` | Dark, slightly cooler |
| `frappe` | Medium dark |
| `latte` | Light theme |
| `roblox` | Matches Roblox's default dark UI |

### Consoles

The console keyboard covers the whole screen, so suggestions show once it's confirmed and closed. While the keyboard is closed, the gamepad controls the terminal:

| Button (Xbox / PlayStation) | Action |
| --- | --- |
| D-pad up/down | Select a suggestion, or browse command history |
| A / Cross | Complete the selected suggestion |
| X / Square | Open the keyboard to edit the input |
| Y / Triangle | Run the command |
| B / Circle | Close the terminal |

Activation keys default to `F2`, so console players need another way to open the terminal. Either add a gamepad button to `activation_keys`, or call `open()` / `toggle()` from your own input handling.

## Custom Log Timestamps

Override the default timestamp format by providing a `format_date` function.

<CodeBlockTabs groupId="lang" defaultValue="luau" persist>
  <CodeBlockTabsList>
    <CodeBlockTabsTrigger value="luau">Luau</CodeBlockTabsTrigger>
    <CodeBlockTabsTrigger value="ts">TypeScript</CodeBlockTabsTrigger>
  </CodeBlockTabsList>
  <CodeBlockTab value="luau">
```lua
centurion_ui.configure({
    format_date = function(log)
        -- log.response.timestamp is a Unix timestamp
        return os.date("%H:%M:%S", log.response.timestamp)
    end,
})
```
  </CodeBlockTab>
  <CodeBlockTab value="ts">
```ts
import type { Log } from "@rbxts/centurion-ui";

CenturionUI.configure({
    format_date: (log: Log) => {
        return os.date("%H:%M:%S", log.response.timestamp) as string;
    },
});
```
  </CodeBlockTab>
</CodeBlockTabs>
